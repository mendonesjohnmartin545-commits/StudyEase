STUDYEASE PLATFORM – UPDATED VERSION WITH OUR TEAM PAGE

HOW TO OPEN LOCALLY
1. Extract this ZIP file.
2. Open the studyease_platform folder.
3. Double-click index.html to open the website in a browser.
